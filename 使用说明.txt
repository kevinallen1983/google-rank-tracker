Google 排名监控工具 - 使用说明

本工具提供两个版本，功能完全相同，只是打开方式不同，按需选用：
  A. GoogleRankTracker.exe        —— 浏览器版：双击后自动打开系统浏览器看板
  B. GoogleRankTrackerDesktop.exe —— 桌面窗口版：双击直接弹出软件窗口（不弹浏览器）
两个版本可放在同一文件夹共存，配置和排名数据（config.json / rank.db）通用。

【一、首次使用】
1. 把选中的 exe 放到任意文件夹（建议新建一个专用文件夹）。
2. 双击该 exe。
   - 浏览器版：系统浏览器自动打开看板；没打开就手动访问 http://127.0.0.1:5000
   - 桌面窗口版：直接弹出软件窗口（里面就是同一套看板）
3. 在"基础配置"里填写：
   - 你的网站域名，例如 kcce-event.com
   - SerpBase API Key（到 https://serpbase.dev 注册获取，新用户有免费额度）
   - 目标国家 / 语言（做欧美生意默认 美国 us / 英语 en）
4. 点"保存配置"。
5. 在"监控关键词"里添加你要跟踪的词：
   - 支持批量：直接把多行关键词粘贴进文本框（每行一个，或用逗号、分号分隔），点"添加"一次加完。
6. 点"立即检查全部"查所有词；只想查某一个词时，点该词右侧的"检查"按钮单独查它。
7. 等待几十秒，下方就会显示最新排名。

【二、每天自动检查（可选）】
- 点"设置每天定时" -> 弹出权限请求时点"是" -> 之后每天 09:00 自动查排名并存入数据库。
- 随时点"查看任务状态"确认是否已启用；不想自动跑了点"取消定时"。
- 注意：电脑关机时不会跑；开机后若错过时间，可在任务计划程序里勾选"如果错过计划开始时间，立即运行"。

【三、查看结果】
- 每次双击 exe，即可看"最新排名概览"和"排名趋势"历史图。
- 所有数据存在 exe 同目录的 rank.db（标准 SQLite 数据库）。

【四、注意事项】
- 本工具必须联网（要调用 SerpBase API 查谷歌搜索结果）。
- 首次运行可能被 Windows 安全提示拦截（SmartScreen），点"仍要运行"即可，本工具不含任何危险内容。
- 免费 API 额度用完后需要充值，否则检查会失败（失败原因见同目录 check.log）。
- 仅支持 Windows 10 / 11 的 64 位系统。
- 桌面窗口版需要 Microsoft Edge WebView2 运行时（Win10 20H2 及以后 / Win11 基本自带）；若打开失败并提示安装 WebView2，按提示到 https://go.microsoft.com/fwlink/p/?LinkId=2124703 安装后重试（极少数精简系统可能没有）。

【五、换电脑 / 重装】
直接把 exe 复制走即可，配置和数据库都在它旁边的文件里，一起复制就保留历史数据。
